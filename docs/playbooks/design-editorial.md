# Design playbook: editorial

Read this for newsletters, reports, long PDFs, manuals and other reading-heavy work.

- Reading comes first. Comfortable measure (about 45–75 characters per line),
  generous leading, no widows or orphans in visible places.
- A real type hierarchy with few levels, used consistently: title, section,
  subhead, body, caption.
- A grid that repeats across pages, with planned moments that break it: an opening
  spread, a big number, a full-bleed image. Long documents need rhythm.
- Make it navigable: contents, page numbers, running heads, clear section starts.
- Data is design: charts and maps that answer a question, labeled directly.
- For interactive editions, the content must work with animation off, and on a phone.
- Never rewrite supplied text without being asked. If it comes from a client's
  document, keep it literal and flag anything that looks wrong.

## Deliver

The final file (PDF or HTML), the editable source, and the list of open content
questions.

# Design playbook: presentations

Read this for decks and slides.

- Ask how it will be used: **presented** (little text, big ideas, the speaker
  carries it) or **read alone** (self-sufficient, more text). They are different
  designs, and most bad decks are an accident between the two.
- One idea per slide, stated in the title as a sentence, not as a topic.
- Before visuals, outline the story slide by slide: setup, tension, resolution, ask.
- Build on the master layouts of the tool it will live in, so others can edit it.
- Readable from the back of the room: large type, few elements. Test at projected
  proportions.
- Motion only where it explains a sequence.
- Check fonts exist where it will be shown, or embed them; export a PDF fallback.

## Deliver

The editable deck in the requested format, a PDF, and speaker notes if presented.
